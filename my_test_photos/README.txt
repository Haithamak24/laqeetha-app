Put your own test photos here (NO ID cards, those go in private_test_photos).
Name each file  <label>__<anything>.jpg  so the test knows the right answer, e.g.
  earbuds__1.jpg   flash__2.jpg   wallet__desk.jpg   bottle__a.jpg
Short labels: earbuds, flash, wallet, phone, keys, headphones, laptop, tablet, charger, bottle,
backpack, handbag, glasses, watch, bracelet, notebook, umbrella, jacket, scarf, calculator,
pencilcase, powerbank
Then run test.bat. It compares the two AI label sets on these photos and keeps the better one.
